## Getting Started

### Prerequisites

List the software, tools, or dependencies needed before installation:

```bash
- Node.js v18+
- Python 3.8+
- npm or yarn
```

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/kaveen1212/whatsapp-automation-agent-langgraph.git
   ```

2. Navigate to the project directory
   ```bash
   cd whatsapp-automation-agent-langgraph
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Set up environment variables
   ```bash
   cp .env.example .env
   ```
